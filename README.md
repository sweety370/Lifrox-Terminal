LIFROX TERMINAL

ANDROID TERMINAL ENVIRONMENT

---

A new look. A familiar terminal.

Lifrox Terminal is a customized version of Termux focused on providing a clean, lightweight, and customizable terminal experience on Android.

---

OVERVIEW

- Custom application identity and icon
- Lightweight terminal environment
- Linux command-line tools support
- Open-source development
- Built for Android devices
